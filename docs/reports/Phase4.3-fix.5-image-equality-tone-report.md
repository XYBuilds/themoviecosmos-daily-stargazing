## 2. 技术实现 (Implementation)

### 2.1 问题定位
4.3-fix.3 验证产出（`output/phase4.3-fix.4-verify/publish_draft_v4.md`）暴露发布稿是「影评人 / 策展人机位」：俯视、替读者盖章（「击中人心」「提醒我们」）、给冷门片补偿性拔高（「不算喧哗的热点，更像是一声被时间留下来的回响」）。补偿性拔高本质是怜悯而非平等，仍在用「热度 / 质量」尺子排座次，与项目主题相悖。

### 2.2 核心设计：机位转向 + 单一权威源
- **价值观分层**：对外品牌叙事保留「未来考古主义」；对内用可执行口径「影像平权 / 无差别的注视」。
- **叙述者从「影评人机位」转向「平视机位」**：不因热度 / 评价 / 年代改变语气，不排名、不找补、不吹捧。
- **调性契约作为单一权威源**（ADR-0013 D3）：把可执行 checklist（平视不排名 / 去态度盖章 + 禁用词 / 数据文字化 / 共振并置 + 时间可选）沉淀进 ADR，供 C2 及未来各平台变体 / UI 文案统一引用，杜绝跨环节调性漂移。
- **关键边界**：平视是「姿态」而非「比喻」，严禁博物馆 / 考古表层词（物证 / 藏品 / 出土），项目不在表面呈现博物馆 / 天文馆概念。

### 2.3 compose_publish.md 落地（5 块）
1. 身份段：随刊作者 → 平视机位操作性描述。
2. 职责边界：新增「平视不排名」（含冷门/热门/两极三种接受度平视写法示例）+「去态度盖章」（含禁用词清单）两条。
3. 内容结构·共振钩子：镜像 → 并置（「同一种人类处境」），时间维度降级为可选佐料。
4. 正例：替换为平视版（砍补偿性拔高 + 态度盖章，接受度用平视写法，共振用并置写法）。
5. 反例：补「补偿性拔高 / 替读者盖章」一类，列举具体禁形。
