# 共振重定义为「表层 + 逻辑」、LLM-judge 转评测预筛、POV 聚焦能力分两步引入

**Status**: accepted (D1–D5, Phase 3.10 GATE go 2026-06-10); D6–D8 pending Phase 3.11

> **背景**：Phase 3.9 于 2026-06-09 `GATE no-go` 结案（见 [`output/Eval/phase3.9/GATE_RESULT.md`](../../output/Eval/phase3.9/GATE_RESULT.md)）。结案后总编对本轮做了三点观察：① LLM-judge 在观察集校准达标（exact 0.639 / pearson 0.743 / within-one 1.0，**采信**），效果可用于减轻人工筛选；② 人工与 judge 的分歧并非噪声，而是系统性的定义错位；③ 人类感受到的共振常含**视角变换**（如从洪水中将溺亡的孩子视角讲述），当前管线无此能力。
>
> 复盘的硬证据来自本轮 152 个「人工×judge」配对打分的混淆矩阵（`output/Eval/phase3.9/llm-judge-scores.json`）：
>
> | | judge=0 | judge=1 | judge=2 | 行合计 |
> | --- | --- | --- | --- | --- |
> | **human=0** | 72 | 15 | 0 | 87 |
> | **human=1** | 14 | 17 | 5 | 36 |
> | **human=2** | **0** | 14 | 15 | 29 |
>
> 三个关键事实：① judge **从未**把人工强共振（human=2）判成 0（`within_one=1.0` 的体现）——预筛安全性的根基；② 当 `judge≥1` 放行模拟时，**human=2 留存 29/29（100%）**、human=0 筛掉 72/87（83%）、总量砍 57%；③ `human=2 & judge=1` 的 14 例**全部** judge 给了 1（无一给 0）——judge 看到了一层共振、没看到双层，正是定义错位的活样本。
>
> **核心命题（post-3.9）**：四个改进点不是独立的四件事，而是**一条有依赖的链**——`共振定义（基石）→ 分歧分析（证据）→ judge 预筛（收益）；POV（一种"同逻辑、异结构"的生成机制）`。本 ADR 把这条链钉死，并把 POV 与定义/预筛**分两步**引入，避免重蹈 3.8/3.9「一次动太多、分不清谁起作用」的覆辙。

## 14 例分歧归因（D1 的证据基础）

`human=2 & judge=1` 的 14 例干净地裂成两种系统性缺口：

**Gap A（8 例）· judge 判「表层沾边」**：有共享的具体锚点，但 judge 用「骨架同构」严判后认为结构不同。

| 新闻 | 电影 | judge 拒绝理由（节选） |
| --- | --- | --- |
| 电网停电危机 | Survival Family | 机构危机应对 vs 个人在崩溃中求生 |
| AI 裁员重组 | At War / The Plan | AI 重组 vs 毁约抵抗 / 个人失业计划 |
| 边境执法收紧 | Sicario / Transpecos | 移民政策 vs 缉毒战 / 机构腐败 |
| 议员初选爆冷 | The Campaign | 真实权力博弈 vs 虚构讽刺 |
| 奥德赛选角文化战 | L'Odissea | 现代再现之争 vs 古典神话叙事 |

→ 人看到的是**同一条因果引擎**（稀缺/系统失效 → 逼人进入求生模式），只是**视角与尺度变了**（机构↔个体）。judge 读字面结构判「不同构」。**Gap A 同时坐实 D1 与 D6，并证明二者本质同一件事。**

**Gap B（6 例）· judge 判「深层共振（仅结构）」**：无具体锚点，judge 仅凭抽象权力角色（权威↔被牺牲者）给 1，人给 2。

| 新闻 | 电影 | judge 承认的结构 |
| --- | --- | --- |
| AI 裁员 | Bounty Killer | 权威为「更大善」牺牲个体 |
| Google 反垄断 | The International / Clearstream | 机构问责强权 |
| 冰球黑马夺冠 | Run Silent Run Deep | 领袖克服失败带队 |

→ 「权威↔受害者」过不了 0 分守门（换条无关机构新闻同样能套上），它属于**逻辑轴**而非表层锚点。**Gap B 上人偏松；新定义后应回到 1。**

## 决策

### D1 · 共振重定义为「表层元素 + 底层逻辑」（双轴）

| 条目 | 定稿 |
| --- | --- |
| **第一轴 · 表层元素** | **具体、可命名、过得了 0 分守门**的共享元素（这个地点 / 这类职业 / 这种事件类型 / 这个设定题材）。判据：换条无关新闻**无法**复用 = 承重表层锚点。**抽象权力角色配对（权威↔受害者、领袖↔团队）不算表层，归逻辑轴** |
| **第二轴 · 底层逻辑**（替换原「结构性共振 / 骨架同构」） | **在 POV / 尺度变换下不变的因果-赌注引擎**：新闻与电影**实例化同一句「X 在约束 Z 下驱动 Y」**，哪怕一个在机构尺度讲、一个在个人尺度讲，也算共振 |
| **可证伪反测（防给分膨胀）** | 写不出一句两边都成立的「因果/赌注」句子（如：*系统性稀缺把普通人逼入求生*）⇒ **不算逻辑共振**，退回 0/1。「逻辑」比「骨架同构」宽（接纳 POV 变换），又不滑成「什么都给分」 |
| **2×2 矩阵不变，仅换措辞** | `结构性共振 → 逻辑共振`；`深层共振（仅结构）→ 深层共振（仅逻辑）`；`强共振（表层 + 结构）→ 强共振（表层 + 逻辑）`。无表层+无逻辑=0 / 单轴=1 / 双轴=2 |
| **追认性质** | 总编自述「打分其实早按表层+底层逻辑打」——新定义是让白纸黑字的 rubric 与 judge 对齐人类**已在用**的标准，而非凭空放宽 |

### D2 · 不动历史标注，3.10 全新起算

| 条目 | 定稿 |
| --- | --- |
| **冻结 3.9 旧标注** | 152 个旧分在旧定义下打，**永久冻结为 legacy**，不重标、不假装与新定义可比 |
| **3.10 全链全新起算** | 3.10 用同一新闻集**重跑全链**（生成 + 检索 + 打分），一律用新双轴定义 |
| **judge 重校准搬进 3.10** | 用 3.10 观察集**新定义鲜标**做校准锚——彻底解耦对历史数据的依赖 |
| **19 例分歧分析已完成使命** | 14 Gap + 5 over-call 的归因已把定义钉实（见上），不再正式重标 |
| **旧基线降 legacy** | 3.8/3.9 的 2 分率数字降为 legacy，新定义起算一条新基线 |

### D3 · 分两步引入，隔离 POV 这个新变量

- **3.10**：仅换新双轴定义 + 重写并重校准 judge + judge 预筛进评测工作流。生成侧**不动**（POV 推迟）。产出一条干净的新定义**复检基线**。
- **3.11**：引入 POV 聚焦生成能力，用 POV 诊断标签测净增量。
- **理由**：3.10（POV-off）天然成为 3.11（POV-on）的**对照臂**——同新闻、同定义、同 judge，唯一变量是聚焦。这是 3.8/3.9 一直缺的干净 A/B。

### D4 · LLM-judge 转评测预筛（想法 1）

| 条目 | 定稿 |
| --- | --- |
| **rubric 重写** | judge prompt 从「骨架同构」改写为 D1 双轴（POV 不变因果引擎 + 具体表层 + 0 分守门 + 强制输出因果反测句作 rationale） |
| **全量打分、不删** | judge 给全部候选打分，**物理上一个不删** |
| **分档分流** | `judge=0` → 降级堆（默认不进人工）；`judge≥1` → 人工复核（省下的工作量）；`judge=2` → 高亮优先 |
| **拒绝集抽审（防自我蒙蔽）** | 每 run 人工额外**盲评 `judge=0` 堆随机 k%**；一旦捞到 `human=2` ⇒ 门槛不安全，放宽。这是预筛上线后**唯一**能持续监控「100% 留存」的手段 |
| **阈值纪律** | 阈值 `judge≥1` 先暂定，**必须在 3.10 观察集（新 def、新 judge）验证「零 human-2 被杀」才冻结**——不搬旧数据结论 |
| **闸门分母诚实** | 桶对照在「放行 + 抽审样本」集上算，抽审样本按抽样率回加权 |
| **scope** | 仅**评测打分循环减负**（当前瓶颈，见 ADR-0006 D4）；**不碰生产日报选片**——那是后续 |

### D5 · 3.10 砍 Q1'、A1 降只读参照

| 条目 | 定稿 |
| --- | --- |
| **删除 Q1' 删除闸** | 生成侧未变，拿新定义重跑「中性能否替代 A1」无新信息。A1 删除判定整个搁置到 POV（3.11）真正改变生成之后再议 |
| **A1 仅只读参照** | A1 仍并跑、仅作只读质量参照，不进任何闸 |
| **3.10 成功标准（两条）** | ① **共振侧**：新双轴定义下 combo 桶 2 分率 **>** pure_fact 桶，obs/holdout 不裂口；② **工作流侧**：预筛达成工作量削减（目标 ~50%+）且**零 human-2 被杀**（抽审证实）+ judge 校准达标（采信） |
| **本质** | 3.10 不开新赌注，而是「用修正后的尺子 + 减负工具给组合拳一次诚实复检」，把 POV 干净地留给 3.11 |

### D6 · POV（focalization）= 派生式聚焦能力（想法 3）

> **能力现状调查结论**：当前 persona **做不到** POV。它只有 **valence 取景**（谁是英雄/反派）+ **P-Tone 语气**，pseudo 始终是第三人称、站在事件外。「从溺亡孩子视角讲」是 **focalization（叙事视点）**，管线无此层。

| 条目 | 定稿 |
| --- | --- |
| **派生而非自由选** | focal 视点从**本 persona 价值轴的 Who 极**派生（The-Caregiver→受影响的脆弱者；The-Hero→守护者；The-Sage→抽离观察者；The-Lover→关系中人），**不引入新的自由参数**——POV 是既有 persona lens 从 valence 到 vantage 的更深表达 |
| **只在编剧（P-Tone）步生效** | 唯一书写散文的步骤；**alt-creator / salience / 中性通道一律不动**，保住 ADR-0006 理顺的架构 |
| **硬守卫（继承并扩展铁律）** | focal 角色**必须是 decon 既有 `who-*`**；POV 只换「从谁的眼睛看」，**绝不新增内心戏/事件/因果/结果**；hypernym 锚要求保留；运行时守卫校验 focal-char ∈ decon |
| **产品定位（总编决策）** | POV 是**底层必备的表达能力**，从底层逻辑上必须**允许**换视角；**进检索/生成层（路线 B）**，宁可匹配暂时变差也先把能力建起来再调优 |
| **呈现层未决** | 是否在 Phase 4 文案（reader-facing）做 POV，**暂不决定**；本 ADR 仅锁定检索层 |
| **质量二义性澄清** | 区分**匹配质量**（搜到的片是否真共振）与**讲述质量**（讲得动不动人）。POV 提升讲述；若伤匹配，靠 D7 追加式 + D8 漏斗兜底，不以「动人地卖错片」为代价 |

### D7 · POV 追加式，度量降为调优指南针

| 条目 | 定稿 |
| --- | --- |
| **追加而非顶替** | POV pseudo 作为**新增通道**，与既有第三人称 toned + 中性 n1 **并存**去检索；**绝不**顶替第三人称（顶替会让原本搜到的好片消失 = 匹配地板塌陷） |
| **纯增召回** | 追加式下 POV 只会**多搜到片**，锁死匹配地板；多出的噪声由 D4 预筛 + D8 漏斗吸收——这正是「预筛让追加 POV 烧得起」的闭环 |
| **度量降级** | 既然 POV 是底层必备、不会被砍，3.11 度量从「判决闸」降为**调优指南针**：测「哪个 persona 的 POV 有用、哪里伤匹配、往哪调」，而非「要不要 POV」 |
| **度量双管** | ① **召回归因（A/B 池差）**：POV-recalled 集 = 3.11(POV-on) 召回而 3.10(POV-off) 同新闻未召回的片；其新定义 2 分率 = POV 召回价值。② **`POV变换` 子标签**：标记某个 2 是否「靠视角/尺度变换才看得出来」（Gap A 那类），区分「多召回」与「解锁新一类强共振」 |
| **预测试先行** | 正式 A/B 前，先**手工** POV 重写几条新闻跑检索，差集里**真有新共振片**才值得做全套；否则砍掉省一轮 |

### D8 · 候选过多 · 四层漏斗（D7 追加式的必要配套）

> 追加式的代价是候选膨胀，不处理会恶化评测信噪比（回到 3.9 那 118 例 both-low）。零件大多已有，3.11 串成分层漏斗。

| 层 | 机制 | 来源 |
| --- | --- | --- |
| **1 去重** | POV 大量命中与第三人称**同一片**，按 `tmdb_id` 合并即塌；真正新增的只有「POV 独家片」 | 现有 |
| **2 汇聚排序** | 被**多视角同时命中**（第三人称 + POV / 多 persona）的片排前——经得起换视角看 = 精度信号；弱 POV 独家片沉底 | 扩展现有撞车票 |
| **3 judge 预筛** | 滤掉放大后池子里 `judge=0` | D4（3.10 已建） |
| **4 硬预算上限** | 排序 + 预筛后只给人工 **top-N**（按预算定） | 现有 top-k |
| **安全扣** | 上限以下、但 `judge≥1` 的片 → 进 D4 拒绝集抽审池；**控量用排序+预算，保安全用门槛+抽审，两套旋钮分开** | — |

**铁律**：**绝不靠调高 judge 门槛控膨胀**——那会直接威胁「零 human-2 被杀」。

## 为什么这能解决问题

1. **共振定义对齐人类已在用的标准** ⇒ judge 校准与闸门第一次量在「对的尺子」上，14 例分歧两头收口（Gap A→2、Gap B→1）。
2. **judge 预筛 + 抽审** ⇒ 人工瓶颈砍 ~57%，且漏杀被持续监控、不自我蒙蔽。
3. **分两步 + 天然对照臂** ⇒ POV 的净增量第一次可被干净归因，不与定义变更混淆。
4. **POV 追加式 + 四层漏斗** ⇒ 底层必备能力得以建立，匹配地板不塌、膨胀可控。

## 后果 / 已知局限（诚实记录）

- **新基线与旧不可比**：D2 冻结历史 ⇒ 3.10/3.11 数字不能直接对比 3.8/3.9；靠 run 内对照（A1 参照、三桶、A/B）自证。
- **judge 只看 news summary + movie overview**：预筛是独立第二意见（优点），但评不了「管线靠巧妙 POV 建立的关联」——这也是 POV 要进检索层、而非只靠 judge 的理由之一。
- **POV 主要失败模式 = 事实漂移**：靠 D6 硬守卫（focal ∈ who-* / 不新增事实）+ 预测试 + 运行时守卫兜底。
- **分布漂移**：judge 校准在手挑 eval 新闻上；接 RSS（Phase 5）后须在新分布重测对齐再当预筛。
- **呈现层 POV 悬而未决**：reader-facing 的 POV 价值最大处（Phase 4）本 ADR 未决，登记为 OPEN。
- **候选膨胀的二阶成本**：检索/打分开销上升；靠预算上限与并发控制，属可调旋钮非地基风险。
