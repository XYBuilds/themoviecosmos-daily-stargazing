# 产品方向：从「追求绝妙的非显然共振」转向「事件逻辑驱动、表层亦合法」

**Status**: accepted

## 决策

放弃「**必须**实现绝妙的、非显然的结构共振（权力/命运/反讽）」作为产品标准。新方向：

- **表层 / 题材 / 语境共振是合法的产品成果**，不再被当作"低级"或假阳性（孟买新闻命中孟买电影、灾难新闻命中灾难片，都算数）。
- **结构共振仍然要**，但实现路径变了：不再显式追求骨架同构（删除 skeleton 等机制），而是交给 **事件逻辑解构（起因/经过/结果）+ 创作 agent 对解构素材的再加工**，由再加工后的 pseudo 去匹配 overview 时自然涌现。

## 为什么

Phase 3 评测中，过度追求「绝妙非显然共振」效果不好——候选几乎只到 1、出不了 2。诊断为**新闻倒金字塔 vs overview 钩子的信息结构错位**（先抛结果 vs 先铺设定），而非共振哲学本身。与其逼一个苛刻且难稳定命中的目标，不如承认表层共振的价值，并用事件逻辑碎片化让 pseudo 与 overview「同尺寸、同叙事重心」对齐。

## 后果 / 已知局限

- **闸门重心转移**：`eval-the-bet.md §5.1` 第 1 条（≥60% 出 2 分）在新尺子下容易过、证明力弱；**第 2 条（创作 2 分率 > 基线）成为真正的验收点**——它是唯一回答「A2/A4/A7 是否比 A1 白描多带来共振、多 agent 编剧室是否值得」的测试。第 2 条不过 → 结论是「创作视角是过度设计」。
- **保留最小体温计**：评分阶段总编顺手标 `共振类型 ∈ {表层, 结构, 双重}`，使第 2 条能比"结构/双重 2 分率"，看清创作视角的增量来源。它由**总编打分时填**，不由解构 agent 产出（解构层保持零解读）。
- **SSOT 待改清单（留到 v0.4 一次性提进，现仅记账）**：
  - `PRD §1.2 / §1.3`「**绝妙的**讽刺/反差/隐喻」「绝妙的宿命隐喻」与本转向冲突，需改写为新口径。
  - `prompts/_shared/deentification_rules.md` 硬规则 2/4（禁真实地名/精确数字）与「表层共振合法、孟买该能命中孟买片」冲突——需放宽为「承重时可有意识保留专名/具体元素」，否则表层转向在 pseudo 层被重新抹掉、空转。
  - `CONTEXT.md` `共振` 词条已含表层定义，基本兼容；必要时微调去掉"非显然"暗示。
  - `scripts/summarize_eval.py` 若要自动算 `structural_2_rate`，需解析 `共振类型`（代码改动，基础版管线跑通后再接）。
