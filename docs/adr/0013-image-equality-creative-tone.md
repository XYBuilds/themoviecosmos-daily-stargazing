# 影像平权：随刊文案从「影评人机位」转向「平视机位」

**Status**: accepted（价值观决策与调性契约拍板于 2026-06；落地随 Phase 4「4.3 No-Go 整改」循环 4.3-fix.5 实施，见 [`.cursor/plans/Phase4-copywriter-c1-c2.plan.md`](../../.cursor/plans/Phase4-copywriter-c1-c2.plan.md)）

> **本 ADR 的性质**：产品价值观决策 + 可执行调性契约。它承接 [ADR-0012](0012-compose-responsibility-split-and-db-fullcolumn-lookup.md) 把发布稿（C2 `compose_publish`）认定为「唯一创作环节」之后，进一步定义这一环节**用什么姿态创作**。算法口径（双轴 judge / fragment ladder）全部沿用 [ADR-0009](0009-fragment-ladder-and-search-unit-architecture.md)、[ADR-0007](0007-logic-resonance-judge-prescreen-and-pov-focalization.md)，本 ADR 不涉及检索与评分。

## 背景

[ADR-0012](0012-compose-responsibility-split-and-db-fullcolumn-lookup.md) 把 `compose` 收敛为「投影（决策卡）+ 创作（发布稿）」两个非对称环节后，4.3-fix.3 用真实新闻重跑发布稿，产出落在 `output/phase4.3-fix.4-verify/`。验证中发现：**发布稿的口吻是「影评人 / 策展人机位」**，与项目主题相悖。具体病征：

1. **俯视、替读者盖章**：出现「击中人心」「提醒我们」「逼迫角色」等替读者下判断、动员情绪的措辞——作者在替读者感动，而非让读者自己感受。
2. **给冷门片补偿性拔高**：如 `publish_draft_v4.md` 中「它不算喧哗的热点，更像是一声被时间留下来的回响」。这句的潜台词是「虽然冷门，但其实有价值」——它仍在用「热度 / 质量」这把尺子给电影排座次，只是偷偷把冷门的那部捞起来安慰。这是**怜悯**，不是**平等**，反而强化了「冷门 = 需要辩护」的等级。

根因：发布稿缺少一个明确的**叙述者姿态 SSOT**。「平视、不排名」这一产品价值观此前只存在于创作者意图中，从未落进任何指导性文本（PRD 核心理念段只讲「共振 + 引流」，全库无一字提平等）。下游每个创作 prompt 只能各自揣摩调性，必然漂移。

## 决策

### D1 · 确立产品价值观「影像平权」

随刊文案以**平视**的目光对待每一部人类影像作品：不因它热度高低、评价好坏、年代远近而改变语气，**不排名、不找补、不吹捧**。所有电影在叙述者眼中地位平等，无优劣冷热之分。

- **对外品牌叙事**：可表述为「未来考古主义」（保留神秘感与传播性）。
- **对内可执行口径**：用「影像平权 / 客观 / 无差别的注视」——因为创作 prompt 需要的是可操作姿态，不是品牌词。

### D2 · 叙述者从「影评人机位」转向「平视机位」

| 维度 | 旧（影评人机位） | 新（平视机位） |
| --- | --- | --- |
| 立场 | 俯视：我懂它的好，解读给你听 | 平视：平静呈现它是什么、被怎样接受 |
| 判断 | 替读者盖章（「击中人心」「提醒我们」） | 去判断：陈述事实，读者自己感受 |
| 冷门片 | 补偿性拔高（「被时间留下的回响」） | 不拔高：同一副语气，与热门片一视同仁 |
| 数据 | 暗示「受欢迎程度 = 价值高低」 | 数据=接受度事实，与褒贬解耦 |
| 共振 | 电影（过去）映照我们（现在），有古今高下 | 电影与新闻并置，同记一种人类处境 |

> **关键澄清**：平视是一种**姿态**，不是一个**比喻**。严禁用「物证 / 藏品 / 出土 / 档案馆登记」这类博物馆 / 考古的表层词汇落到文案——项目不在表面上呈现博物馆 / 天文馆概念。「平等」靠「不排名 + 不补偿」实现，不靠隐喻包装。

### D3 · 调性契约作为下游创作 prompt 的单一权威源

本 ADR 末尾的「调性契约 checklist」是所有面向读者创作环节的**单一权威源**。当前由 C2（`compose_publish.md`）引用；未来 Stage 1 的各平台定稿变体（Discord / 小红书 / X，原 4.4–4.7）、UI 文案、站外文案均须引用同一份清单，**不得各自重新发明调性**，以杜绝跨环节漂移。

## 调性契约 checklist（创作 prompt 引用入口）

面向读者的文案须逐条满足：

- [ ] **平视不排名**：用同一副语气描述所有电影的接受度。冷门不拔高、热门不吹捧、两极不站队。读者应能感到这部电影的传播广窄与口碑形态，但正文不暗示「因此它好 / 不好、值不值得看」。
  - 接受度的平视写法示例：冷门好评→「它在看过的人那里收获了温和的好感，只是始终没能成为被很多人谈论的电影」；热门高分→「它被很多人看过，也几乎得到了一致的认可」；两极争议→「喜欢它的人和无法忍受它的人，几乎一样多」。
- [ ] **去态度盖章**：不替读者下判断或动员情绪。禁用词（含但不限于）：「击中人心」「提醒我们」「令人动容」「不容错过」「值得一看」「快去看」，以及任何补偿性拔高（「虽然冷门，但其实……」「被时间留下来的回响」）。
- [ ] **数据文字化**：不裸露评分数值 / 票数 / 热度指数 / 来源平台名（TMDb / IMDb 等）。DB 数字只作判断依据，落到正文翻译成文字。
- [ ] **共振并置 + 时间可选**：共振钩子写成「电影与这条新闻触到了同一种人类处境」的并置，而非「电影映照当下现实」的镜像。时间维度是可选佐料——电影年代与新闻形成张力（如多年前的片子预演了今天的事）可自然点出；无此张力则不提，不强行制造古今对照。
