# 优质候选判据：多 agent 共振为主、命中分为辅；A1 从「对照」改为「平权 agent」

**Status**: proposed（草案 · 待 §证据 的样本扩充后定稿；本 ADR 不解封 Phase 4，闸门口径见后果）

> 背景：Phase 3.5 新管线落地、`GATE_FAIL（发布）` 之后，总编对 N=10 产物做了人工评估，并对 9 条「多 agent 命中」候选补填了 `共振分` / `共振类型`。本 ADR 记录由此得出的产品判据与角色调整。承接 [ADR-0002](0002-pivot-to-event-logic-resonance.md)（表层共振合法化）。

## 决策

### D1 · 「优质候选」的定义

- **主判据 = 多 agent 共振（An + An）**：同一部电影（`tmdb_id`）被 **≥2 个 agent** 命中即视为优质候选准入。A1 平权后（见 D2）也算其中一个 An。
- **二级 = `pseudo 命中分` 仅作排序 / containment 截断 / 打平键，不作质量闸**。
- **延后门槛**：暂不要求 A1 必须在场。**若后续数据显示「纯创作 An+An（不含 A1）」的质量明显低于「含 A1 的 An+An」，再增设 A1 必要门槛**。当前 N=10 中纯创作 An+An 样本数为 0，无法判断，故显式延后。

### D2 · A1 从「实验对照 / 锚定」改为「偏好写事实的平权 agent」

- A1 不再是「要被创作组打败的基线」，也不是 D1 里强制的「现实锚」。它就是**一个偏好客观白描的普通 agent**，与 A2/A4/A7 同地位参与召回与共振。
- 直接后果：**MVP 验收闸门必须重写**（见后果）。

### D3 · 去实体化（de-entification）从「全局统一」下放为「按 persona 分配」

- 不再让所有 agent 用同一套硬屏蔽规则。屏蔽强度成为**每个 persona 的实体预算**：A1 倾向保留客观实体（地名/数字/客观专名），创作 agent（A2/A4/A7）各按自己的镜头决定抽象程度。
- 排除「完全不屏蔽」方案（会污染召回分布、破坏下游中文文案的去实体化口吻）。
- 本质是把 ADR-0002 已开的「load-bearing 专名/数字例外」从全局例外，进一步**结构化为 per-persona 策略**。

### D4 · 弹性 pseudo 配额 = 「选择优先、分配延后」；不预定义「灵感」

- 放弃「每 agent 固定写 3 段」对新闻—persona 适配度的无视。
- **关键判断**：不要把「灵感」定义成生成前、可自评的主观量（LLM 自评不可靠）。**「灵感」= 已实现的召回适配度**，由下游召回质量（是否命中、是否与其他镜头共振、是否落双重）事后揭示。
- 因此当前阶段把它做成**选择问题（生成后按已实现适配筛选）**，而非**分配问题（生成前预测配额）**。等积累足够 `(新闻特征 × persona → 是否落地)` 数据，再回头学一个适配预测器去做生成前分配（省 token）。两阶段路线。
- 近期三条具体改动（低成本、不依赖预测器）：
  1. 把「3」从**配额**改为**上限**，允许 agent 写 1–3 段、或对低适配新闻**跳过**（沿用契约已有「失败可跳过」语义，扩一条「无适配可跳过」）。
  2. 给每段 pseudo 设**质量地板**（相似度 / 共振下限）；**未过地板的 pseudo 不得参与 D1 的多 agent 信号**——否则注水 pseudo 会伪造假的多 agent 共振，直接污染主判据（比候选爆炸更毒）。
  3. **保镜头多样性（广度优先于深度）**：富余预算先保证「尽量多的不同镜头各出 1 段强的」，再给高适配 agent 加码；禁止单 agent 灌满、饿死其他镜头。

## 为什么（证据 · N=10 / 9 条多 agent 候选）

总编对 9 条多 agent 候选打分后：

| hit分 | 片名 | agents | per-agent | 共振分 | 类型 |
|---:|---|---|---|---:|---|
| 17 | Survival Family | A1,A7 | A1:12,A7:5 | 2 | 双重 |
| 15 | Hurricane Season | A1,A7 | A1:9,A7:6 | 1 | 表层 |
| 13 | Terra Nova | A1,A4 | A1:6,A4:7 | 0 | — |
| 10 | Assembling a Generator | A1,A7 | A1:4,A7:6 | 2 | 双重 |
| 9 | Alice in Wonderland | A1,A7 | A1:3,A7:6 | 0 | — |
| 8 | Mirreyes contra Godínez | A1,A2 | A1:3,A2:5 | 1 | 双重 |
| 8 | Machete | A1,A2 | A1:5,A2:3 | 2 | 双重 |
| 7 | Poem of the Sea | A1,A2 | A1:4,A2:3 | 2 | 双重 |
| 6 | Transpecos | A1,A2 | A1:4,A2:2 | 2 | 双重 |

- **多 agent 是有效的精度过滤器（支撑 D1 主判据）**：5/9 为 2 分、7/9 ≥1 分、仅 2 条彻底 0 分。
- **命中分在优质集内部几乎反向（支撑 D1 二级降级）**：分最高的三条 → 2/1/**0**；分最低的三条 → **2/2/2**。命中分不能用来排优质候选，只配做截断/打平。
- **多 agent 落地几乎都是双重（这才是其价值）**：7 条 ≥1 分里 6 条双重、1 条表层 —— 镜头交汇 ≈ 表层+结构同时成立。
- **盲点（支撑 D1 延后门槛 + D2 待测项）**：A1 出现在 **9/9** 里，纯创作 An+An 样本为 0。疑似 A1 是「分布磁铁」（白描贴 TMDB 分布、召回面广），则「多 agent」可能只是 1.5 张独立票。**这是 A1 平权后最该持续测量的东西**；同时注意那 2 条 0 分恰是「创作 agent 压过 A1」的样本（弱信号，N 太小不下结论）。

## 后果 / 已知局限

- **闸门重写（D2 的硬后果）**：`eval-the-bet.md §5.1` 第 2 条「创作 2 分率 > A1 基线」随 A1 平权而失效。新验收点应围绕**多 agent（An+An）候选的 2 分率 / 双重率**。`scripts/summarize_eval.py` 的 `structural_2_rate baseline vs creative` 口径需相应改造。
- **样本量**：所有定量结论基于 N=10 / 9 条多 agent 候选，**只够定方向、不够定阈值**。D1 的延后门槛、D2 的「分布磁铁」嫌疑都需更多批次验证；故本 ADR 为 `proposed`。
- **不解封 Phase 4**：本 ADR 是方法论决策，与 `output/Eval/GATE_RESULT.md` 的 `GATE_FAIL` 不冲突；C1/C2 等仍 gated。
