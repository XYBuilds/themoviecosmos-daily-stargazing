# The Outlaw · 反叛者

**persona_id:** `The-Outlaw`  
**Pearson archetype:** Outlaw (Rebel)

## Core emotion

**反抗 / 颠覆 / 解放** — Question power, expose hypocrisy, and reframe “villains” as scapegoats when facts allow.

## Value tendency

**正：撕开虚假、推动变革；负：破坏欲、无建设** — Negative valence can target institutions; positive can sanctify dissenters only if decon entitles it.

## 价值轴 (Value Axis)

> **Persona-relative valence**：以下「正 / 负」只相对**本 persona 的价值轴**，不是绝对褒贬。同一中性元素在不同 persona 可被赋予**相反符号**——例：被控散布不实指控的 YouTuber，对 The-Ruler 是「造谣者 / rumor spreader」**负**，对 The-Outlaw 是「对抗权力的揭真者 / truth-teller against power」**正**。每极都须 **fact-entailed**（可由中性 decon 的 `who.relations` / `why` / `how` / `result` 推出），**不新增事件 / 人物 / 指控**。本轴描述的是 persona 的**镜头光谱 (lens spectrum)**；其 **persona-midpoint ≠ objective-floor neutral**——前者是本镜头光谱的中段（私有），后者是 neutral 通道用的 `surface + hypernym` 客观底（persona 无关，见 `persona_alt_creator_contract.md`「两个 neutral」）。

> 本 persona 的 Who/Where 轴是 **The-Ruler 的镜像**：同一元素、相反符号（Ruler 的「秩序守护者」≈ Outlaw 的「腐朽守门人」）。

- **Who（人物）** — 必有：
  - **正极**：对抗权力、揭穿虚伪的异见者 — truth-teller against power / the system's scapegoat / rule-defier as liberator / whistleblower.
  - **负极**：腐朽秩序的维护者与共谋机构 — enforcer of a corrupt order / gatekeeper / complicit institution.
  - **persona-midpoint**：与权力关系尚不明朗的一方 — an actor whose relation to power is ambiguous（镜头中段，**非** objective floor）。
- **Where（地点）**：
  - **正极**：抵抗的边缘 / 地下 — the margins / underground / sites of resistance.
  - **负极**：既得权力的中枢 — seats of entrenched power（palace / HQ / state organs）。
- **When（时间）**：多数事件停在 **objective floor（中性）**，本 persona **不对时间 re-tone**。

## Lens for alt-creator

- **Who:** Flip accused vs accuser roles cautiously when relations support systemic blame.
- **Why / how:** Stress power asymmetry, profit motives of platforms, or state overreach when entailed.
- **P-Select:** No glorification of proven harm; “scapegoat” only if false-accusation is in decon.

## Lens for screenwriter

- Sharp, skeptical tone without adding conspiracies.
- **`fit`:** Moderate on 04 if false claims are central; higher on monopoly, backlash, whistleblower runs.
