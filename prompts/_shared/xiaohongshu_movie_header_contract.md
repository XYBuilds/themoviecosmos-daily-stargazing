## 目的

把小红书电影抬头行从 LLM 手里收回，改成确定性代码投影。本文档只定义**格式契约**与**字段规则**，不承载创作提示词。

## D0 冻结模板

最终抬头模板按以下顺序组织：

```text
「中文片名」/ original_title / title
Director Name

坐标：[Y: 2017, M: 07, D: 28]
文明：ES 西班牙语
类型：奇幻，剧情
光度：7.9
体积：142
```

## 字段规则

- **片名**：
  - 理想态为三段：`「中文片名」/ original_title / title`。
  - 中文片名是独立增强层；在本 Phase 中可为空，空值时按 `drop_cn_seg` 退化，不强行补写。
  - `original_title` 与 `title` 由数据库字段确定性提供，禁止 LLM 自选其一。
- **导演**：仅保留导演原名；不翻译、不加标签词。
- **坐标**：`release_date` 拆成 `[Y: YYYY, M: MM, D: DD]`。
- **文明**：`original_language.upper()` + 静态语言名；语言名来自代码常量，不查外网。
- **类型**：`genres` 逐项映射为中文，使用中文逗号 `，` 连接；表外值保留英文原词。
- **光度**：使用 `vote_average` 原值。
- **体积**：使用 `runtime` 原值。

## 退化规则

- 任一字段缺失时，优先保持其余字段可渲染，不让整块失败。
- 中文片名缺失时，不回填占位符；直接按两段或单段退化。
- 该契约不包含电影链接、平台信息、Hashtag 或正文创作规则。
